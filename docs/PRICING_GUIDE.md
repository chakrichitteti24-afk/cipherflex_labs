## 🛡️ Core Company Policies (Non-Negotiable)

1. **Third-Party Costs Borne by Client:**
   - Hosting (Vercel, Render, AWS, VPS), custom domain, platform fees (Make.com, Zapier, Twilio), and AI model API usage (OpenAI, Gemini) are billed directly to the client's own accounts/cards.

2. **Strict Scope & Revision Limits:**
   - Every project includes up to **2 rounds of revisions**.
   - Additional features or scope changes are quoted separately at ₹1,000/hr ($20/hr) or as fixed add-ons.

3. **Standardized Boilerplates:**
   - Projects are accelerated using production-ready boilerplates and modern tech stacks (React, Vite, Next.js, Supabase, Tailwind CSS) for fast delivery.

4. **Payment Milestones:**
   - **50% Advance Deposit** before starting.
   - **50% Final Payment** upon staging demo and before live deployment/handover.
